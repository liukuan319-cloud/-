# 班枢正式版执行计划

依据：用户七项正式版需求及 2026-10-09 补充确认。当前分支 `codex/class-ai`，最终推送远端 `main`。

## 已确认的约束

- 全班共用邀请码；姓名或学号与有效名单匹配后登录。默认拒绝名单外用户，管理员可启用自助加入。
- 移除身份恢复入口并停用恢复接口，不再向用户发送恢复凭证。
- 删除成员采用移出班级：作废登录，从有效名单、登录匹配和当前统计中移除，保留通知与历史记录（用户明确确认）。
- 课表、值日由班干部手填或 CSV 导入数据库。AI 只查询、回答和提出建议，网页按钮确认写入。
- 学号仅供管理和登录，不提供给模型成员查询工具。
- 每阶段完成运行 `pnpm build` 和 `pnpm test`；最后检查服务端类型、浏览器布局、远端迁移及部署。
- 不将密钥、真实名单、本机数据库或环境文件提交 GitHub。

## 顺序与验收

| 阶段 | 交付 | 关键检查 |
| --- | --- | --- |
| 1 | 成员批量导入、0002 迁移、管理入口 | 50 人、重复行、错误行、成员权限拒绝 |
| 2 | 名单登录、自助加入开关、邀请码重置、移除恢复 | 名单内登录、名单外拒绝、旧码失效 |
| 3 | 角色调整、移出成员 | 权限即时变化、失效会话、历史保留 |
| 4 | 课表和值日持久化、手填/CSV、AI 查询扩展 | 班级隔离、学号脱敏、无数据回答、只读工具 |
| 5 | 清理用户可见示例流程 | 入口、导航、对话、设置及接口提示 |
| 6 | 苹果风视觉、胶囊按钮、进度环 | 桌面与移动宽度、减少动画、真实进度或不定进度 |
| 7 | 综合验收、文档、GitHub 与 Cloudflare | 构建测试、迁移、提交一致性、健康接口 |

各阶段的实际执行结果记录在 `upgrade-progress.md`，未实测事项不能列为已通过。
