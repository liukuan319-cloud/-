# 学业数据口径

课程由班级共用，成绩和综测分数按成员保存。班干部可录入并查看本班指定成员的数据；普通成员只能查看自己的数据。CSV 成绩导入使用 `course,credits,score`（或 `课程,学分,成绩`）三列，学期和课程类别由导入表单指定。已有同学期同名课程的类别或学分不一致时，该行不会覆盖原课程。

成绩范围为 0 到 100 分。绩点采用四分制分段换算：90-100 为 4.0，85-89 为 3.7，82-84 为 3.3，78-81 为 3.0，75-77 为 2.7，72-74 为 2.3，68-71 为 2.0，64-67 为 1.5，60-63 为 1.0，低于 60 为 0。小数分数按同样的下限比较。学期和累计 GPA 均为 `sum(课程学分 × 绩点) / sum(已录入成绩的课程学分)`，最后四舍五入到两位；未录入成绩的课程不参与分母。未有成绩时 GPA 为 `null`。

已修学分只统计成绩不低于 60 的课程，分别按必修、选修、通识累加。学分目标由班级设置。综测包括德育、智育、体育、美育、劳育五项，每项录入 0 到 100 分；返回的平均分仅对已录入项取算术平均，不代表学校的正式加权综测分。学校口径不同时应调整换算或权重后再用于正式评定。
