# 测试说明

## 自动测试

`tests/backend.test.ts` 使用 Node 内置 `node:sqlite` 创建独立内存数据库，应用真实 SQL 迁移，再通过 Hono 的 `app.request` 调用路由。D1 `batch` 适配为 SQLite 事务。测试不连接模型、不访问真实班级、不发消息。

后端测试覆盖：

- 未登录拦截、Cookie 安全属性、创建班级、名单导入及登录、角色调整、成员移出、退出和邀请码更新。
- 跨站写入、无效 JSON、班级隔离。
- 草稿不自动发布、并发重复确认仅发布一次、确认时编辑草稿。
- 普通成员权限、跨班级通知和进度隔离、非法接收人、指定成员任务、后来加入的全班成员。
- 本人完成状态、重复确认幂等、冲突操作版本、操作过期。
- 通知版本、撤回任务及未执行确认、个人聊天记录隔离。
- 日历权限、北京时间转 UTC、日历文本转义与 UTF-8 折行、无效日期及缺失时区。

`tests/ai.test.ts` 覆盖成员姓名脱敏、班级信息、课表和值日、通知、本人待办、工具参数与权限、模型错误和调用轮数限制。模型响应使用模拟服务，不消耗真实模型额度。

2026-10-09 执行 `pnpm test`：**62/62 通过**；`pnpm build`、`pnpm check:server` 通过。本机临时班级真实 AI 问答和线上首页、健康接口另做了人工检查。
