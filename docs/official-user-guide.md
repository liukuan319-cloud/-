# 班枢正式版使用与上线检查

## 班干部

1. 在入口选择创建班级，输入班级名称和本人姓名。
2. 在班级与设置打开成员管理，粘贴名单或上传 UTF-8 CSV。格式为 `姓名,学号,角色,备注`，后三列可留空；角色为“班干部”或“成员”。
3. 检查成功、跳过和失败行，修正失败内容后再次导入。学号优先去重，其次姓名；同班同名成员需在导入前核对名单。
4. 把班级邀请码交给同学。默认只允许名单成员登录；需要接受名单外成员时，在设置启用自助加入。
5. 在班级数据入口维护课表和值日，保存前核对星期、课程时间和成员姓名。
6. 发布通知和任务时检查草稿并点击确认发布。同学自报完成后，可以查看真实统计。

## 同学

输入自己的姓名或学号，以及全班共用的邀请码。名单匹配即登录。换设备或退出后同样使用这两项信息登录。

可以问 AI：“我们班有谁？”“明天有什么课？”“这周谁值日？”“最近七天有什么通知？”“我有哪些逾期任务？”班级数据缺失时应提示暂无数据。

AI 提供查询与建议；发布通知、修改完成状态、保存课表和值日由网页按钮执行。完成状态表示本人自报完成。

## 数据维护

- 重置邀请码后，旧邀请码不能再登录；已登录会话继续有效。
- 移出成员会作废其登录，并从有效名单和当前统计中移除；已发布通知和历史记录保留。
- 角色调整的权限由服务端判断。至少保留一名班干部管理班级。
- 全班共用邀请码及姓名/学号登录属于本作品选定的登录方案；邀请码由班干部管理。

## 上线顺序

```powershell
pnpm install --frozen-lockfile
pnpm build
pnpm test
pnpm check:server
pnpm exec wrangler d1 migrations apply class-ai --remote
```

远程数据库迁移成功后才推送正式版 `main`，以免自动部署后的接口读取尚不存在的字段或数据表。Cloudflare 构建配置参考根目录 README。

部署后检查首页和 `/api/health`，再验证真实班级登录、导入、AI 对话及权限。`API_KEY` 必须保存在 Worker Secret；不要上传 `.dev.vars`、本机数据库或真实成员名单。

自动化测试不替代校园网访问、真实手机输入与日历导入检查；这些项目需要实际设备和网络验证。
